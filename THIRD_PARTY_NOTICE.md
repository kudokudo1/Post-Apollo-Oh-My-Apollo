This repository contains a Post-Apollo shell configuration built from and around several existing shell projects.

## OH MY ZSH

The `.zshrc` file retains substantial structure, comments, and starter configuration derived from **Oh My Zsh**:

https://github.com/ohmyzsh/ohmyzsh

Oh My Zsh is distributed under the **MIT License**.

Post-Apollo changes layer additional history behavior, completion behavior, aliases, tool integrations, environment choices, startup behavior, and other operator-specific configuration on top of that base.

The `.p10k.zsh` file is generated by the **Powerlevel10k configuration wizard** and identifies itself as being based on Powerlevel10k's `config/p10k-rainbow.zsh`.

https://github.com/romkatv/powerlevel10k

Powerlevel10k is distributed under the **MIT License**.

The generated configuration has subsequently been preserved and may contain local Post-Apollo adjustments, but it should not be treated as wholly original Post-Apollo source.
